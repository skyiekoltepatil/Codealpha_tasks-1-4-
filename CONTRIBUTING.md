# Contributing Guidelines

Thank you for your interest in contributing to the **CodeAlpha Internship Tasks** repository!

## 📌 Development Workflow

1. **Fork the Repository**: Create your personal fork on GitHub.
2. **Clone your Fork**:
   ```bash
   git clone https://github.com/<your-username>/Codealpha_tasks-1-4-.git
   cd Codealpha_tasks-1-4-
   ```
3. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/my-enhancement
   ```
4. **Code Standards**:
   - Follow PEP 8 style conventions for Python code.
   - Maintain semantic HTML5 and responsive, accessible CSS for web interfaces.
   - Ensure all unit tests pass before committing.
5. **Run Tests**:
   ```bash
   python3 Task2_FAQ_Chatbot/test_chatbot.py
   ```
6. **Commit & Push**:
   - Use conventional commit messages (`feat:`, `fix:`, `docs:`, `style:`, `test:`, etc.).
7. **Submit a Pull Request**: Provide a clear description of changes made and reference any relevant issues.
