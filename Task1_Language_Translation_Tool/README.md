# Task 1: Language Translation Tool (Fluent)

A sleek, responsive language translation web application built with HTML5, CSS3, and modern Vanilla JavaScript, styled with a macOS frosted glass bento-grid interface.

## ✨ Features

- **Multi-Language Translation**: Instant translation across English, Spanish, French, German, Italian, Japanese, Chinese, Hindi, and Arabic.
- **Bi-directional Swapping**: One-click language and text buffer inversion with smooth synchronization.
- **Real-Time Character Counter**: Live count indicator with a 500-character safety boundary.
- **Clipboard Integration & Toast**: Native clipboard copy with visual checkmark indicator and custom floating toast feedback.
- **Keyboard Shortcuts**: Execute quick translations using `Ctrl + Enter` (Windows/Linux) or `Cmd + Enter` (macOS).
- **Responsive Bento Grid**: Custom CSS grid layout styled with backdrop blurs, glow effects, and mobile-friendly stacking.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser:

```bash
open index.html # On macOS
# Or double click index.html
```

## 🛠️ Tech Stack

- **Markup**: Semantic HTML5
- **Styling**: Vanilla CSS3 (Glassmorphism, CSS Grid, Flexbox, Custom scrollbars)
- **Scripting**: Modern ES6+ JavaScript (`async/await`, Fetch API)
- **API**: Google Translate API (`client=gtx`)
